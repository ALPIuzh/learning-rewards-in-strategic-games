# Third-party code and data

The security-game experiments use
[GUARD](https://github.com/CoffeeAndConvexity/GUARD) at revision
`58964e76f37bdfc32560308a14942677b27148f3`.

That revision has no license file. Permission to redistribute GUARD-derived
Lobeke data and figures remains unresolved; the MAIRL MIT license does not cover
them. These assets are in `experiments/guard/paper/results/` and
`reproducibility/data/lobeke/`.

Python dependencies retain their own licenses; versions are recorded in `uv.lock`.
