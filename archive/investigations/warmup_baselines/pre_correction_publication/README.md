# Pre-correction publication snapshot

This directory preserves the generated publication TeX and build manifest that
were present immediately before the paired-action OLS correction was promoted
to the canonical figure pipeline. The files are retained for auditability and
are not inputs to the corrected paper figures.

The corresponding protected raw run and original compact export remain
unchanged. Corrected publication data live under
`reproducibility/data/lobeke/paired_ols_correction` and
`reproducibility/data/lobeke/final_evaluation_corrected`.
